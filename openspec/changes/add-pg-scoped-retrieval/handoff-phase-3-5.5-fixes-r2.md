## 共同实现方向：不要继续逐例拼正则

现有模型输出仍是自由 claim 字符串，新“结构化关系”只是从字符串抽若干词。优先建立受约束的字段/引用绑定（主体、指标/平均时间、等级、带符号完整值、单位、条件、版本/来源），对照本次实际行/正文，再由应用渲染可信声明；也可保守限定原文逐字声明或已验证模板。无法核验的自由声明应显式 model_failure/partial。

不要求通用自然语言逻辑推理，不新增第二次 LLM 验证，也不通过全拒绝模型正例达标。若调整模型 JSON 接口，可让既有 fixtures 增加必要字段，但不得改变原错误内容、删弱断言或伪装为生产服务复跑。修改被冻结的新验收文件前需另报具体必要接口变化；优先兼容已有规范正确声明。
