# I3公开验收输入

本表在匿名实施前固定。每行需要有效正例、相邻负例和相应边界的真实计数；测试/mock、真实IAM、真实存储、实际模型与浏览器证据分开。

| ID | 正向控制 | 必须拒绝/保持的反例 | 实证 |
|---|---|---|---|
| K01 | 明确local原行为与remote可启动 | 非法/缺配置失败；local不调IAM，remote断网不回local | 启动/真实请求计数 |
| K02 | 人类与service_account分别通过合法形状 | 错schema/issuer/audience、active假、bool修订、把机器套人类或反向均拒绝 | 严格验证+真实IAM样本 |
| K03 | 有效主体先成功访问一次 | IAM/PG/Redis故障后503，无旧正向缓存；恢复正例可用 | 自有故障+下游0 |
| K04 | A/air/knowledge服务账号精确许可 | water、错企业、相似前缀、错受众、无权限下游0；无机器membership/session | 真实IAM+受控收包 |
| K05 | 显式映射及实际技术就绪 | 未映射、错tenant/default/namespace冲突拒绝；local角色不扩大remote授权 | 配置/实际路由 |
| K06 | all为有权且就绪集合 | 显式air+无权water整体拒绝，不裁剪；无库不泄漏名称/计数 | 真实API/后端计数 |
| K07 | query、generate、各网关发送与retry工作 | 前一调用后撤销，下一次新dispatch0；生成回送/落盘时旧作用域不生效 | 真实屏障+收包与持久化回读 |
| K08 | 仍有效机器回收后无许可、重开恢复 | 永久撤销/过期凭据不复活，旧人类ref/ctx在ABA后拒绝 | 真实IAM状态变化 |
| K09 | 本人当前企业记录/缓存/导出可用 | 同名local用户、其他主体类型/企业/旧权限不能命中；cache hit也在线复核 | 记录/缓存/导出回读 |
| K10 | PDF/解析片段/doc/chunk/source合法读取 | 其他库/遍历/旧语料版本/伪造来源404或403且无实际文件读取 | 文件/PG实际计数与指纹 |

| K12 | human知识库会话、选择企业、SSO | 无企业/错成员拒绝，不自动第一家；state/回调/重放拒绝，machine不能切企业 | 真实IAM+浏览器 |
| K13 | 桌面/390×844登录、查询、记录、下载、刷新 | 两标签/A→B→A/退出换账号迟到结果不串；CSRF/Origin及401/403/409/503真实反馈 | 浏览器/Tab/Escape/屏障 |
| K14 | 原local和检索/来源/状态机离线回归 | 不改Gate4结论、不弱化来源完整性/删断言/扩大skip，具体基线失败保留 | pytest/Ruff/node契约 |
| K15 | 差异、秘密、性能、资源交接齐全 | 原库与PDF/解析物未写；不上传token/内部key/真实数据；不以helper延迟冒充端到端 | 元数据指纹/费用账本/命令与退出码 |

现有部署的public/rag资料库、MinerU产物、既有air/water存储只读。新增测试数据只落自有schema/workspace/记录根；需要隔离真实写入夹具时先做所有权清单，禁止全局prune/drop或共享库TRUNCATE。报告指纹是对受影响对象的元数据/既有版本对照，不导出真实敏感语料当证据。
