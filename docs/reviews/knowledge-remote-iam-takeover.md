## 实质补修

- 用请求级 ContextVar 绑定原始身份和在线核验回调；在新数据操作/模型发送、缓存和记录读取、来源文件以及回送/落盘前复核。并发请求不共享原始令牌；缺可信请求作用域的直接 remote 调用关闭。
- AuthContext、缓存键、记录保存/筛选包含人类四修订、会话、机器账号代次、凭据 ID/修订、模式/主体/租户、精确权限与映射版本；旧记录没有新绑定时要求重查。
- 传回并消费真实 context_version，切企业旋转 CSRF/纪元；旧标签页带旧纪元不能借新企业权限。原生来源/导出链接只带非秘密纪元，仍依赖 cookie 身份与在线核验。
- 人类与机器严格分型，补嵌套键、时间格式/有效期、成员修订一致性等检查；协议失败 503 与主体失效 401 分开。remote/local cookie 分名；SSO state 由服务端保存并一次性消费；客户端关闭时释放连接池。
- 补查询可用性、就绪状态、登录/切企业重复提交、初始化迟到响应、remote 记录根、配置错误和监听边界；来源文本明确 UTF-8，真实浏览器确认中文正常。UTF-8 问题为继承问题的附加修复，不另扣模型首交分。
- 将专项测试依赖的私有响应改为仓库内无秘密、可移植的协议夹具；新增实际 HTTP、实际 generate 函数和受控收包反例。
- 补充 DESIGN/UX 记录及局部页面静态检查入口，保持既有视觉结构。
