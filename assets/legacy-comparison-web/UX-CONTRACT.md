# 检索对照页交互合同

视觉由 DESIGN.md 定义。本机中文工具；尚无既有网页组件库，下面是新规范。

## Canonical UI Map

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Form | app.js composer | 当前 Goal 和本合同 | 显式提问/澄清续问 | 浏览器空输入、busy、IME、失败恢复 |
| Select/Listbox | 原生select | DESIGN.md | 系统弹框 | 浏览器键盘与澄清选项 |
| Scrollbar | style.css全局 | DESIGN.md | 原文30rem局部滚动 | 浏览器长原文与窄屏 |
| Toast | query-status区域 | 本合同 | 加载/失败/成功内联aria-live | 浏览器失败与加载状态 |


不把敏感问题放URL或localStorage；刷新不自动重发、重试。只有服务器账本持久化；导出由用户点击。多策略串行后台执行并显式共享同参数检索。生成按钮只用已有record_id，不重新检索。错误保留问题与可用结果，用户自行选择下一次操作。预算耗尽显示原因，不提供自动提额。

范围歧义只列真实目录候选；用户选择后仍要过标准/版本冲突校验。成功返回结果卡片并保持策略选项；记录查询内容只在授权本机成果目录。文件预览仅来源白名单，永不接受任意路径。

键盘Tab顺序与可见顺序一致；焦点环明确；状态有aria-live；320px窄屏、长中文、空结果、失败、加载和减少动态效果均验收。

## 查询选择合同（2026-10-10 用户授权优化）
普通问答每次仅提交一个策略：LightRAG→所选原生模式；PG→pg；PG+LightRAG→pg+所选模式；纯模型→bypass。只有涉及 LightRAG 的路线显示模式下拉。当前普通问答的选择不受隐藏对照勾选影响。
对照实验独立保存勾选，首次进入默认 local / pg+local；提供三路对照预设。选项是一条完整路线，N条路线对应N份分别展示的结果，不是合并N份答案。切换模式或选择只改变控件，不自动查询、生成、增加额度或清除既有结果。刷新回到普通问答local。查询或单卡生成期间锁定全部路线控件。已保存结果明确标为历史本Goal对照，可继续多卡查看，不代表当前普通查询会多路执行。
使用方式和路线由原生 radio 负责键盘和互斥语义；模式、澄清和保存问题筛选沿用原生 select。共享选择映射由 selection.js 提供，app.js 的提交、计数、预览与费用说明均消费同一映射。后端策略API/身份/预算合同不改变。用户确认源为本次界面优化请求及前一条“普通问答/对照实验”建议。
